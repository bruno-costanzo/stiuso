# ciaobrowser

Say goodbye to the browser. ciaobrowser lets AI interact with your Rails app the same way users do — through your existing controllers, with the same authorization, validations, and business logic.

It uses an AI agent to read your controllers and auto-generates [fast-mcp](https://github.com/yjacquin/fast-mcp) tools from them. Your entire Rails app becomes an MCP server that any AI client can use — Claude Desktop, Cursor, ChatGPT, or your own WhatsApp/Slack bot via [RubyLLM](https://rubyllm.com).

## Installation

```ruby
# Gemfile
gem "ciaobrowser"
```

```bash
bundle install
rails generate ciaobrowser:install
```

## Generating Tools

```bash
rails generate ciaobrowser:tools expenses
rails generate ciaobrowser:tools transfers balances
```

For each controller, this generates:
- **Action tools** (index, create, destroy, etc.) - one per routed action
- **InspectModelTool** - returns schema info (columns, enums, validations, associations)

## Configuration

```ruby
# config/initializers/ciaobrowser.rb
Ciaobrowser.configure do |config|
  config.generator_model = "gpt-4o"  # Model for generating tools (needs structured output)
  config.agent_model = "claude-opus-4-5"  # Model for the runtime agent
  config.mcp_url = "http://localhost:3000/mcp"

  # Resolve user from MCP headers
  config.resolve_user = ->(headers) {
    user_id = headers&.dig("x-user-id")
    User.find_by(id: user_id)
  }

  # Inject auth into Rack env for Dispatcher
  config.authenticate_request = ->(env, user) {
    Current.user = user
  }

  # Context the agent receives about the user
  config.user_context = ->(user) {
    "User: #{user.name}, ID: #{user.id}"
  }
end
```

## Using the Agent

```ruby
user = User.find(1)
agent = Ciaobrowser::Agent.new(user: user)

agent.ask("show me my expenses")
agent.ask("create an expense for groceries, $50")
agent.ask("delete expense 123")

agent.stop
```

The agent:
- Asks for missing information instead of failing
- Requires confirmation before create/destroy actions
- Can inspect models to understand enums, validations, etc.

## Architecture

```
External clients (Claude Desktop, Cursor)
        │
        ▼
   fast-mcp server (/mcp/sse)
        │
        ▼
   app/tools/*_tool.rb  ← generated by ciaobrowser
        │
        ▼
   Ciaobrowser::Dispatcher
        │
        ▼
   Rails controllers (existing code, same auth)
```

## How It Works

1. **Install generator** runs `fast_mcp:install`, creates initializers
2. **Tools generator** uses an AI agent (RubyLLM) to analyze your controller
3. The agent reads routes, controller source, model validations
4. It generates MCP tools with proper descriptions and typed params
5. **InspectModelTool** is auto-generated for model introspection
6. **Dispatcher** routes tool calls through your actual controllers
7. **Agent** connects to MCP via ruby_llm-mcp for conversational interface

## Stack

- **fast-mcp**: MCP server infrastructure
- **ruby_llm**: Powers the generator agent AND the runtime agent
- **ruby_llm-mcp**: Connects the agent to MCP tools
